# Tema 3 · Claude Code y Context Window

Tercer tema del curso **[Claude Code .NET](https://www.trainingit.es/producto/claude-code-net/)** de TrainingIT.

El contexto es la información con la que Claude trabaja en cada momento, y la context window es el espacio máximo del que dispone para alojarla, medido en tokens. Su tamaño y el precio por token dependen del modelo, así que elegir modelo es también una decisión económica. En este tema aprendemos a ver qué ocupa esa ventana y cuánto espacio queda libre.

## Vídeos del tema

**3.1 Manejando contexto con Claude Code.** Prompt, tokens, contexto, ventana, modelo y coste forman una cadena: el mismo texto puede ocupar y costar distinto según el modelo.

**3.2 Configuración de la context window.** El tamaño de la ventana en la status line y su desglose con `/context`: system prompt, herramientas, mensajes, espacio libre y buffer de autocompactación.
